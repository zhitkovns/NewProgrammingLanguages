# Параллельный поиск по файлам через каналы

**Тема:** Многопоточность - Rust

## Описание задачи

Аналог `grep`: ищет шаблон во всех переданных файлах параллельно.
Каждый файл обрабатывается отдельным потоком `std::thread::spawn`.
Найденные совпадения (имя файла, номер строки, текст) отправляются в
главный поток через `std::sync::mpsc::channel` - multiple producers,
single consumer.

`mpsc` - стандартный канал Rust. После клонирования `tx` для каждого
потока главный поток делает `drop(tx)` на оригинале - это закрывает
отправляющий конец, после чего `rx.iter()` автоматически завершается,
когда все потоки закончили и закрыли свои клоны. Это идиоматический
паттерн "fan-in".

Результаты сортируются по (имя файла, номер строки), чтобы вывод был
детерминирован независимо от порядка прихода сообщений. Потоки
соединяются через `join()` после сбора всех результатов.

Ошибки чтения файла (`fs::read_to_string` возвращает `io::Result`)
логируются в stderr через `eprintln!` - поток продолжает работу.

`join().expect("thread panicked")` протаскивает панику любого потока
наружу.

## Формат входных и выходных данных

argv: `<pattern> <file1> [file2 ...]`. Выходные данные: строки в
формате `файл:строка:текст` и общее количество совпадений.

## Установка

```bash
sudo apt install rustc
```

## Запуск

```bash
rustc main.rs
./main hello file1.txt file2.txt file3.txt
```
