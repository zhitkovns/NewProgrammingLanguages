# Параллельный поиск по файлам через каналы

**Тема:** Многопоточность - Rust

## Описание задачи

Аналог утилиты grep, который ищет заданный шаблон во всех переданных
файлах параллельно. Каждый файл обрабатывается отдельным потоком
`std::thread::spawn`.

Найденные совпадения (имя файла, номер строки, текст) отправляются в
главный поток через `std::sync::mpsc::channel` (multi-producer,
single-consumer). После клонирования отправителя для каждого потока
главный поток делает `drop(tx)` на оригинале. Это закрывает отправляющий
конец, и `rx.iter()` автоматически завершается, когда все потоки
закончили работу.

Результаты сортируются по имени файла и номеру строки, чтобы вывод был
детерминирован независимым от порядка прихода сообщений. Потоки
соединяются через `join()` после сбора всех результатов.

Ошибки чтения файла логируются в stderr через `eprintln!`, поток
продолжает работу. `join().expect("thread panicked")` протаскивает панику
любого потока наружу.

## Формат входных и выходных данных

Аргументы командной строки: `<pattern> <file1> [file2 ...]`.
Выходные данные: строки в формате `файл:строка:текст` и общее
количество совпадений.

## Установка

Требуется компилятор Rust. В Windows он устанавливается через менеджер
пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id Rustlang.Rustup -e
rustup default stable-msvc
```

Проверка: `rustc --version`.

## Запуск

Выполните компиляцию и запуск (из PowerShell или MSYS2):

```bash
rustc main.rs
./main.exe hello file1.txt file2.txt
```

Ожидаемый вывод:
```text
file1.txt:1: hello world
file2.txt:2: hello from file2
total matches: 2
```
