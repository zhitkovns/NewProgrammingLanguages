# Задача о философах за столом

**Тема:** Многопоточность - Elixir

## Описание задачи

Классическая задача о пяти философах и пяти вилках. За столом сидят
5 философов, между каждой парой соседей лежит одна вилка (всего 5
вилок). Философ по очереди думает и ест. Для еды ему нужны две вилки -
слева и справа.

Программа моделирует вилки как процессы, отвечающие на два сообщения:
`{:take, from}` (взять вилку, ответ `{:ok, pid}`) и `:release` (вернуть).
Философы - тоже процессы; они пересылают сообщения вилкам и ждут
ответа в `receive`.

## Как избегается deadlock

Если все 5 философов возьмут левую вилку и одновременно запросят
правую, наступит взаимная блокировка (circular wait). Классическое
решение - асимметрия: философ с номером 5 берет вилки в обратном
порядке (сначала правую, потом левую). Тогда граф ожидания разрывается,
и один из философов всегда может получить обе вилки.

В коде это одна строчка:
`{first, second} = if id == 5, do: {rf, lf}, else: {lf, rf}`.

## Формат входных и выходных данных

Входных данных нет (число философов и приемов пищи - константы).
Выходные данные - журнал: кто поел и сколько приемов осталось.

## Запуск

```bash
elixir main.exs
```
Порядок событий недетерминирован. В конце - сообщение
simulation finished.
