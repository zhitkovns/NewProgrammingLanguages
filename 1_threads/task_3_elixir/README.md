# Параллельный алгоритм PageRank

**Тема:** Многопоточность - Elixir

## Описание задачи

Вычисление PageRank для ориентированного графа с использованием модели
акторов. Каждая вершина графа представлена отдельным процессом (актором),
который хранит свой текущий рейтинг и накапливает входящие взносы от
соседей.

На каждой итерации главный процесс отправляет каждому узлу сообщение
`{:compute, ...}`. Узел пересчитывает свой рейтинг по классической формуле
PageRank с коэффициентом затухания (d = 0.85) и рассылает обновленный
рейтинг своим соседям через сообщение `{:contribute, ...}`.

Итеративный процесс продолжается до сходимости значений рейтинга вершин:
алгоритм останавливается, когда максимальное изменение веса любой вершины
между текущей и предыдущей итерацией становится меньше заданного порога
(0.0001). Для обмена сообщениями используются встроенные функции
`spawn_link`, `send` и `receive`.

## Формат входных и выходных данных

Входных данных нет, граф задан константой в коде.
Выходные данные - лог итераций с указанием максимального изменения
рейтинга на каждом шаге, сообщение о количестве итераций до сходимости
и итоговые значения PageRank для каждой вершины.

## Установка

Требуется среда Erlang/OTP и Elixir. В Windows они устанавливаются
через менеджер пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id Erlang.ErlangOTP -e
winget install --id Elixir.Elixir -e
```

Проверка: `elixir -v`.

## Запуск

Выполните запуск скрипта из PowerShell (из папки с файлом):

```powershell
elixir main.exs
```

Ожидаемый вывод (значения могут незначительно отличаться из-за
округления, но сходимость должна произойти за 40 итераций):
```text
Iteration 1: max diff = 1.0
Iteration 2: max diff = 0.06375
...
Converged after 40 iterations.
Final PageRank values:
Node 1: 0.1734
Node 2: 0.3321
Node 3: 0.3197
Node 4: 0.1734
```
