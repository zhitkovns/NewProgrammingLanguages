# Параллельный подсчет n-грамм в тексте

**Тема:** Многопоточность - Kotlin

## Описание задачи

Программа подсчитывает частоту появления биграмм (n-грамм для n=2) во
входном тексте. Текст разбивается на слова, которые затем делятся на
равные части (чанки) по количеству потоков.

Каждый поток (`kotlin.concurrent.thread`) обрабатывает свой чанк и
накапливает локальную хеш-таблицу (`HashMap`) с частотами биграмм. Это
позволяет избежать блокировок на этапе подсчета.

После завершения работы потока его локальные результаты сливаются в
глобальную хеш-таблицу. Слияние защищено мьютексом `ReentrantLock` (через
расширение `withLock`), чтобы предотвратить состояние гонки (race
condition). Основной поток дожидается завершения всех рабочих потоков
через `join()`, после чего выводит топ-5 самых частых биграмм.

## Формат входных и выходных данных

Входных данных нет, текст задан константой в коде.
Выходные данные - список из 5 самых частых биграмм с указанием их
количества.

## Установка

Требуется компилятор Kotlin и JVM. В Windows они устанавливаются через
менеджер пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id Microsoft.OpenJDK.21 -e
```
Для самого Kotlin скачайте архив `kotlin-compiler-*.zip` с GitHub и
распакуйте его, добавив папку `bin` в PATH. Проверка: `kotlinc -version`.

## Запуск

Выполните компиляцию и запуск из PowerShell (из папки с файлом):

```powershell
kotlinc main.kt -include-runtime -d main.jar
java -jar main.jar
```

Ожидаемый вывод:
```text
Top 5 bigrams:
kotlin is: 2
is a: 1
a modern: 1
modern programming: 1
programming language: 1
```
