# Параллельная битоническая сортировка

**Тема:** Многопоточность - Ada

## Описание задачи

Реализация алгоритма битонической сортировки (Bitonic sort) для массива
из 8 целых чисел. Алгоритм состоит из последовательности фаз (K) и шагов
внутри каждой фазы (J). На каждом шаге сравниваются элементы, находящиеся
на расстоянии J друг от друга.

Для распараллеливания на каждом шаге для каждой пары индексов (I и I xor J)
создается отдельная задача Ada (task). Задачи запускаются одновременно.
Синхронизация с главной программой осуществляется через механизм рандеву:
главная программа передает параметры (индексы I и J, а также текущую фазу K)
через entry Start. После завершения сравнения и возможного обмена значений
задача сигнализирует о готовности через entry Finish.

Главная программа дожидается завершения всех задач текущего шага, прежде
чем переходить к следующему, что гарантирует корректность сортировки.

## Формат входных и выходных данных

Входных данных нет, массив задан константой в коде.
Выходные данные - две строки: исходный массив и отсортированный массив.

## Установка

Требуется компилятор GNAT. В Windows он устанавливается через среду MSYS2.

1. Откройте терминал MSYS2 UCRT64.
2. Выполните установку пакета:

```bash
pacman -S mingw-w64-ucrt-x86_64-gcc-ada
```

## Запуск

Выполните компиляцию и запуск из терминала MSYS2 UCRT64:

```bash
gnatmake main.adb
./main.exe
```

Ожидаемый вывод:

```text
initial: 5 3 8 1 9 2 7 4 
sorted: 1 2 3 4 5 7 8 9 
```
