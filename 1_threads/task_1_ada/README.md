# Параллельный подсчет простых чисел на отрезках

**Тема:** Многопоточность - Ada

## Описание задачи

Отрезок [2, 100000] делится на 4 равных части. Каждая часть
обрабатывается в отдельной Ada-задаче (task): задача перебирает числа
своего диапазона и для каждого проверяет простоту тривиальным тестом
(`while D*D <= N`). Каждое найденное простое число увеличивает
счетчик через защищенный объект (protected type).

`protected type Counter` инкапсулирует мьютекс: процедура `Increment`
и функция `Value` исполняются под ним автоматически, писать
`Lock`/`Unlock` вручную не надо. Это идиоматический для Ada способ
разделять изменяемое состояние между задачами.

Каждая задача принимает параметры через `entry Start` в блоке `accept`.
Главная программа после запуска всех задач дожидается их завершения
через второй рандеву `accept Finish` - это блокирует вызывающий поток
до момента, когда задача дошла до этой точки.

Число потоков ОС Ada-рантайм выбирает сам, задачи - более высокий
уровень абстракции, чем pthreads.

## Формат входных и выходных данных

Входных данных нет - верхняя граница N задана константой в коде.
Выходных данных одна строка: количество простых чисел на [2, N].

## Запуск

```bash
gnatmake main.adb
./main
```
Нужен компилятор GNAT (sudo apt install gnat).
