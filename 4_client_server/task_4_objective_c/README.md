# Клиент-сервер для игры Морской бой

**Тема:** Клиент-серверное взаимодействие - Objective-C

## Описание задачи

Программа представляет собой упрощенную клиент-серверную реализацию
игры Морской бой на TCP-сокетах. Один и тот же исполняемый файл может
запускаться как в режиме сервера, так и в режиме клиента.

Сервер хранит фиксированное игровое поле 5x5 с расставленными кораблями.
Он принимает подключение одного клиента и в цикле обрабатывает выстрелы.
Клиент отправляет координаты, сервер проверяет попадание, обновляет
состояние поля и отправляет ответ (HIT, MISS, INVALID). Игра
продолжается, пока не будут потоплены все корабли, после чего сервер
отправляет GAME OVER.

Код написан на Objective-C (компилируется как .m файл) с использованием
сетевой библиотеки Windows Winsock2. Использование фреймворка Foundation
и библиотек GNUstep намеренно исключено для обеспечения максимальной
стабильности и кроссплатформенности сборки в среде Windows.
Обрабатываются ошибки создания сокета, привязки, подключения и обмена
данными.

## Формат входных и выходных данных

Входные данные - текстовые координаты выстрелов (строка).
Выходные данные - текстовые ответы сервера и лог в консоли.

## Установка

Требуется компилятор Clang. В Windows он устанавливается через MSYS2.

1. Откройте терминал MSYS2 UCRT64.
2. Выполните установку пакетов:

```bash
pacman -S mingw-w64-ucrt-x86_64-clang
```

## Компиляция

Выполните компиляцию из терминала MSYS2 UCRT64 (из папки с файлом).
Используется флаг -Wl,--subsystem,console для работы в консольном режиме
и -lws2_32 для подключения сетевой библиотеки Windows:

```bash
clang main.m -o game.exe -lws2_32 -Wl,--subsystem,console
```

## Запуск

Откройте два окна терминала (MSYS2 UCRT64 или PowerShell).

В первом окне запустите сервер:

```bash
./game.exe server
```

Сервер выведет сообщение и будет ждать подключения. Во втором окне
запустите клиент:

```bash
./game.exe
```

Вводите координаты (например, A1, B4, E5) и нажимайте Enter. Для выхода
введите Q. Поле сервера 5x5 (1 - корабль, 0 - пусто):
A1 A2, B4, C2 C4, D2, E4 E5 - это координаты всех 8 кораблей.

Ожидаемый вывод сервера:
```text
Battleship server listening on port 8084
Client connected
Shot at A1 -> HIT (ships left: 7)
Shot at C1 -> MISS
...
Shot at E5 -> HIT (ships left: 0)
```

Ожидаемый вывод клиента:
```text
Connected to server. Enter coordinates (e.g., A1, B4). Type Q to quit.
> A1
HIT (ships left: 7)
> C1
MISS
...
> E5
GAME OVER
```
