# TCP-клиент с таймаутом

**Тема:** Клиент-серверное взаимодействие - Erlang

## Описание задачи

TCP-клиент к 127.0.0.1:8080 с до 3 попытками подключения и паузой
1 секунда между ними. После успешного подключения отправляет
"Hello from Erlang client", читает до 1024 байт ответа с таймаутом
5 секунд. Если ответ не пришёл за 5 секунд - печатает
"timeout waiting for response" и завершается.

## Описание реализации

Используется модуль `gen_tcp` из стандартной библиотеки Erlang -
сторонних зависимостей нет.

`connect_with_retries` - рекурсивная функция с двумя аргументами
(номер попытки и максимум попыток). На каждой итерации вызывает
`gen_tcp:connect/4` с таймаутом 1000 мс. При ошибке печатает в stderr
причину (`econnrefused`, `timeout` и т.д.), ждет 1 секунду через
`timer:sleep` и рекурсивно пробует снова. После исчерпания попыток
возвращает `{error, connect_failed}`.

`send_and_receive` - после успешного подключения отправляет сообщение
через `gen_tcp:send/2`, затем вызывает `receive_response`.

`receive_response` - ключевая функция с таймаутом. `gen_tcp:recv/3`
принимает сокет, длину (0 = «любой доступный кусок») и таймаут в
миллисекундах. При истечении таймаута возвращает `{error, timeout}`,
что обрабатывается отдельной ветвью `case` и печатает
"timeout waiting for response".

Сокет открывается с опциями `[binary, {packet, 0}, {active, false}]`:
- `binary` - данные приходят как `<<binary>>`, не как строка
- `{packet, 0}` - без разбора на пакеты (сырые байты)
- `{active, false}` - пассивный режим, чтение только через `recv`

## Формат входных и выходных данных

Сервер на 127.0.0.1:8080. Отправляется одна строка, читается ответ.
В stdout - диагностика (номер попытки, статус подключения, отправленные
и полученные данные, таймаут). Ошибки - в stderr через
`io:format(standard_error, ...)`.

## Установка

Erlang/OTP есть в стандартных репозиториях Ubuntu:

```bash
sudo apt install erlang
```

## Запуск
```bash
erlc main.erl
erl -noshell -s main main -s init stop
```
Первая команда компилирует main.erl в main.beam. Вторая запускает
функцию main/0 без интерактивной оболочки и завершает VM после
её выполнения.

Перед запуском клиента нужен работающий сервер на 127.0.0.1:8080
(например, task_1_odin). Успешный вывод:

```text
attempt 1 of 3
connected
sent: Hello from Erlang client
received: Hello from Erlang client
```
Проверка таймаута - запустить "молчащий" сервер, например
nc -l 127.0.0.1 8080, и клиент выведет:

```text
attempt 1 of 3
connected
sent: Hello from Erlang client
timeout waiting for response
```
