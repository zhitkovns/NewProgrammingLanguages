# TCP-сервер операций над матрицами

**Тема:** Клиент-серверное взаимодействие - Zig

## Описание задачи

Программа реализует TCP-сервер и TCP-клиент для выполнения операций
сложения над матрицами. Сервер слушает порт 8082 на локальном хосте.
Клиент подключается к серверу, отправляет данные и получает результат.

Протокол обмена данными:
1. Клиент отправляет 4-байтовое целое число N (размер матрицы).
2. Клиент отправляет данные первой матрицы (N*N 32-битных целых чисел,
   little-endian).
3. Клиент отправляет данные второй матрицы (аналогично).
4. Сервер вычисляет сумму элементов двух матриц и отправляет результат
   обратно клиенту в том же бинарном формате.

Обе программы используют стандартную библиотеку Zig (`std.Io.net`) для
работы с TCP-сокетами. Клиент также написан на Zig и использует
встроенные средства для сериализации массивов чисел в байты.

## Формат входных и выходных данных

Входные данные - бинарный поток от клиента (размерность и две матрицы).
Выходные данные - бинарный поток (результирующая матрица) и лог в консоли.

## Установка

Требуется компилятор Zig. В Windows он устанавливается через менеджер
пакетов winget.

Выполните в PowerShell:
winget install --id zig.zig -e

Проверка: zig version.

## Компиляция

Выполните компиляцию сервера и клиента из PowerShell (из папки с файлами):

zig build-exe main.zig
zig build-exe client.zig

После успешной компиляции в папке появятся файлы main.exe и client.exe.

## Запуск

Откройте два окна терминала PowerShell.

В первом окне запустите сервер:

.\main.exe

Сервер выведет сообщение и будет ждать подключения. Во втором окне
запустите клиент (предварительно перейдите в ту же папку):

.\client.exe

Ожидаемый вывод клиента:
Result matrix: { 6, 8, 10, 12 }

Ожидаемый вывод сервера:
Matrix TCP server listening on 127.0.0.1:8082
Client connected
Matrix size: 2x2
Result sent, server stopping
