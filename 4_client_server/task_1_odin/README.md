# TCP-эхо-сервер на несколько подключений

**Тема:** Клиент-серверное взаимодействие - ODIN

## Описание задачи

TCP-сервер на 127.0.0.1:8080. Принимает до 3 клиентов последовательно
(одно соединение за раз, без форков - этого достаточно для
демонстрации). Для каждого клиента: читает данные в буфер 4 КБ
циклом (recv до закрытия), печатает принятое, отправляет эхо обратно,
закрывает.

Используется `core:net` - это стандартный пакет ODIN, не сторонняя
библиотека. Endpoint собирается из IPv4-адреса (4 байта) и порта.
`net.listen_tcp` возвращает сокет-слушатель и ошибку; `accept_tcp`
возвращает сокет клиента, endpoint и ошибку; `recv_tcp`/`send_tcp` -
соответственно.

Обработка ошибок: каждый из четырех системных вызовов может вернуть
ошибку - все проверяются. `listen` - фатально (`os.exit(1)`), `accept`
- предупреждение и continue, `recv`/`send` - предупреждение и разрыв
соединения.

## Формат входных и выходных данных

Вход - TCP-байты от клиента. Выход - те же байты обратно. В консоль -
диагностика (подключение клиента, полученное сообщение, ошибки).

## Установка

ODIN нет в apt. Скачивается с https://odin-lang.org/docs/install/.
На Linux обычно достаточно распаковать архив в `~/.local/` и добавить
`odin` в PATH.

## Запуск

```bash
odin build main.odin -file
./main
```
После запуска сервер печатает server listening on 127.0.0.1:8080
и блокируется на accept_tcp - ждёт подключения клиента. Это
нормальное поведение, программа не зависла. Сервер работает
последовательно: одно соединение за раз, до 3 подключений.

## Демонстрация работы

Нужны два терминала: один для сервера, второй для клиента.

**Терминал 1** - запуск сервера:

```bash
./main
```

Вывод:

```
server listening on 127.0.0.1:8080
```

**Терминал 2** - подключение клиентом через `nc`:

```bash
nc 127.0.0.1 8080
```

Если `nc` не установлен: `sudo apt install netcat-openbsd`.

После подключения введите строку и нажмите Enter:

```
hello from nc
```

Сервер вернёт эхо - в терминале с `nc` появится та же строка:

```
hello from nc
```

**Терминал 1** в этот момент покажет:

```
client 1 connected
received 14 bytes
```

Чтобы завершить соединение - `Ctrl+C` в терминале с `nc`. Сервер
напечатает `received 0 bytes` (recv вернул 0 - клиент закрыл
соединение) и перейдёт к ожиданию следующего клиента.

Повторите подключение ещё 2 раза (всего 3 клиента). После третьего
закрытого соединения сервер выведет:

```
server stopped
```

и завершится - цикл `for i in 0 ..< 3` закончился.
