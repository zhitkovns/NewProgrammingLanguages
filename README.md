# NL_2026

Индивидуальная работа: 20 программ на 20 разных языках программирования.
Пять тем, на каждую тему - по 4 программы

## Языки

Ada, D, Elixir, Groovy, Haskell, Julia, Lua, Kotlin, ML, Mojo, Objective-C,
ODIN, Perl, Ruby, Rust, Scala, Scheme, Erlang, Zig, Lisp

---

## Тема 1. Многопоточность

Папка: `1_threads/`

| № | Задача | Язык | Папка |
|---|--------|------|-------|
| 1 | Параллельная битоническая сортировка | Ada | `task_1_ada` |
| 2 | Параллельный поиск по файлам через каналы | Rust | `task_2_rust` |
| 3 | Параллельный алгоритм PageRank | Elixir | `task_3_elixir` |
| 4 | Параллельный подсчет n-грамм в тексте | Kotlin | `task_4_kotlin` |

1.1 **Ada.** Реализация алгоритма битонической сортировки для массива чисел. Начальный массив разбивается на части, которые сортируются в параллельных задачах с использованием рандеву для синхронизации на этапах слияния битонических последовательностей.

1.2 **Rust.** Аналог утилиты grep. Каждый файл обрабатывается в отдельном потоке `std::thread`. Найденные совпадения (имя файла, номер строки, текст) передаются в главный поток через канал `mpsc::channel` для последующей сортировки и вывода.

1.3 **Elixir.** Вычисление PageRank для графа с использованием модели акторов. Каждая вершина графа представлена отдельным процессом, который обменивается сообщениями со своими соседями. Итеративный процесс продолжается до сходимости значений рейтинга вершин: алгоритм останавливается, когда максимальное изменение веса любой вершины между текущей и предыдущей итерацией становится меньше заданного порога.

1.4 **Kotlin.** Подсчет частоты n-грамм (последовательностей из n символов или слов) в большом тексте. Текст разбивается на части, каждая часть обрабатывается в отдельном потоке, локальные счетчики объединяются под мьютексом `ReentrantLock`.

## Тема 2. Алгоритмические задачи

Папка: `2_algorithms/`

| № | Задача | Язык | Папка |
|---|--------|------|-------|
| 1 | Рекурсивное сопоставление строк с шаблоном | Haskell | `task_1_haskell` |
| 2 | Бинарное дерево поиска: вставка, обход, высота | Scala | `task_2_scala` |
| 3 | Поиск минимального вершинного покрытия дерева | Scheme | `task_3_scheme` |
| 4 | Построение суффиксного массива | Lua | `task_4_lua` |

2.1 **Haskell.** Рекурсивный алгоритм сопоставления строки с шаблоном, содержащим символы подстановки (например, `*` и `?`). Используется рекурсивный спуск с возвратом и сопоставление с образцом по спискам символов.

2.2 **Scala.** Реализация бинарного дерева поиска через алгебраический тип данных. Операции вставки, поиска, симметричного обхода и вычисления высоты реализованы рекурсивно с использованием pattern matching.

2.3 **Scheme.** Рекурсивный поиск минимального вершинного покрытия для дерева. Используется динамическое программирование на деревьях: для каждого узла вычисляется два состояния - с включением узла в покрытие и без него.

2.4 **Lua.** Построение суффиксного массива для заданной строки. Используется алгоритм префиксного удвоения с рекурсивной сортировкой суффиксов по их рангам.

## Тема 3. Ввод/вывод в консоль и файл

Папка: `3_io/`

| № | Задача | Язык | Папка |
|---|--------|------|-------|
| 1 | Анализ WAV-файла | D | `task_1_d` |
| 2 | Слияние отсортированных бинарных записей | Julia | `task_2_julia` |
| 3 | Анализ структуры PNG-файла с проверкой CRC | Perl | `task_3_perl` |
| 4 | Парсер и сериализатор INI | Ruby | `task_4_ruby` |

3.1 **D.** Программа для чтения и анализа заголовка WAV-файла. Извлекает информацию о частоте дискретизации, количестве каналов, разрядности и длительности аудио. Обрабатывает ошибки чтения и некорректные заголовки.

3.2 **Julia.** Чтение двух бинарных файлов, содержащих отсортированные записи (например, структуры с числовым ключом). Выполняется слияние записей в один отсортированный бинарный файл с сохранением структуры данных.

3.3 **Perl.** Разбор структуры PNG-файла на уровне байтов. Программа читает сигнатуру и последовательно извлекает чанки (IHDR, IDAT и т.д.). Для каждого чанка вычисляется и проверяется контрольная сумма CRC32, выводятся метаданные изображения.

3.4 **Ruby.** Парсер и сериализатор конфигурационных файлов формата INI. Поддерживает секции, комментарии и пары ключ=значение. Преобразует файл в хеш-таблицу и обратно, обрабатывает ошибки форматирования.

## Тема 4. Клиент-серверное взаимодействие

Папка: `4_client_server/`

| № | Задача | Язык | Папка |
|---|--------|------|-------|
| 1 | UDP-сервер разрешения имен | ODIN | `task_1_odin` |
| 2 | TCP-сервер операций над матрицами | Zig | `task_2_zig` |
| 3 | Сервер сетевых семафоров | Erlang | `task_3_erlang` |
| 4 | Клиент-сервер для игры "Морской бой" | Objective-C | `task_4_objective_c` |

4.1 **ODIN.** UDP-сервер, эмулирующий службу разрешения имен. Принимает текстовое имя хоста от клиента и возвращает соответствующий IP-адрес из статической таблицы. Обрабатывает потерю пакетов и некорректные запросы.

4.2 **Zig.** TCP-сервер для выполнения операций над матрицами. Клиент отправляет размерность и данные матриц, сервер выполняет сложение или умножение и возвращает результат обратно по TCP-соединению.

4.3 **Erlang.** Распределенный сервер сетевых семафоров. Клиенты по TCP-соединению запрашивают захват или освобождение семафоров. Сервер ведет учет состояния семафоров и ставит клиентов в очередь ожидания при их недоступности.

4.4 **Objective-C.** Клиент-серверная реализация игры "Морской бой" на TCP-сокетах. Сервер хранит состояние игровых полей, обрабатывает выстрелы клиентов, определяет попадания и отправляет ответы клиентам. Клиент отправляет координаты выстрелов и отображает результаты.

## Тема 5. Конвертация данных

Папка: `5_convert/`

| № | Задача | Язык | Папка |
|---|--------|------|-------|
| 1 | Преобразование плейлиста M3U в JSON | Groovy | `task_1_groovy` |
| 2 | Конвертация списка целых в S-выражение | ML | `task_2_ml` |
| 3 | Конвертация изображения PBM в SVG | Lisp | `task_3_lisp` |
| 4 | Извлечение каталога файлов из ZIP в CSV | Mojo | `task_4_mojo` |

5.1 **Groovy.** Парсинг плейлиста в формате M3U и его сериализация в формат JSON. Программа извлекает названия треков, исполнителей и длительность, формируя валидный JSON-документ.

5.2 **ML.** Рекурсивная конвертация списка целых чисел в строковое представление S-выражения (например, `(1 2 3 4)`) и обратный парсинг строки в список целых чисел с обработкой ошибок формата.

5.3 **Lisp.** Парсинг изображения в текстовом или бинарном формате PBM и конвертация его в векторный формат SVG. Каждый черный пиксель или группа пикселей преобразуется в прямоугольник `rect` внутри SVG-файла.

5.4 **Mojo.** Программа парсит центральный каталог архива, извлекает имена файлов, их размеры и методы сжатия, после чего сохраняет эти метаданные в текстовый файл CSV.
