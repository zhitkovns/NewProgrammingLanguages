# Список целых <-> S-выражение

**Тема:** Конвертация данных - Standard ML

## Описание задачи

`listToSexp` собирает строку вида `(1 2 3 4 5)` из списка int. Пустой
список дает `()`. Используются `String.concatWith` и `List.map Int.toString`.

`sexpToList` - обратная операция. Сначала проверяются внешние скобки
через `String.sub`. Внутренность режется на токены через `String.tokens`
с предикатом `isSpace` (пробел и табуляция). Каждый токен парсится
`Int.fromString`; невалидный - `Fail` с указанием токена.

Парсинг сделан рекурсивным по структуре списка (через `List.map` и
`List.foldl` для суммы), как и положено в функциональном стиле. Пустой
список обрабатывается отдельным случаем в pattern matching.

Обработка ошибок: неправильная форма sexp, невалидный токен внутри -
`raise Fail "..."` с описанием.

## Формат входных и выходных данных

Входных данных нет (список задан в main). Выходные данные:
закодированная строка, декодированный список, сумма, поведение для
пустого списка.

## Запуск

```bash
mlton main.sml
./main
```
Альтернативно: sml main.sml (зависит от реализации). mlton дает
быстрый компилированный бинарник.
