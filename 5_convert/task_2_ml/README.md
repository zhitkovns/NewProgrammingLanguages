# Конвертация списка целых в S-выражение

**Тема:** Конвертация данных - Standard ML

## Описание задачи

Программа выполняет двустороннюю конвертацию между списком целых чисел
и строкой в формате S-выражения (например, (1 2 3 4 5)).

Функция listToSexp рекурсивно склеивает элементы списка в строку,
разделяя их пробелами, и оборачивает результат в круглые скобки.

Функция sexpToList выполняет обратную операцию: проверяет наличие
внешних скобок, разбивает внутреннюю часть на токены по пробелам и
пытается преобразовать каждый токен в целое число.

Обработка ошибок реализована через пользовательское исключение
ParseError. Исключение возбуждается, если строка не обернута в скобки
или если внутри встречается нечисловой символ.

Весь код обернут в блок local ... in ... end, чтобы скрыть внутренние
функции от интерактивного интерпретатора Poly/ML и оставить в консоли
только результаты работы программы.

## Формат входных и выходных данных

Входных данных нет, список и тестовая строка заданы в функции main.
Выходные данные - результаты конвертации и сообщение об ошибке парсинга.

## Установка

Требуется компилятор Poly/ML. В Windows он устанавливается с
официального сайта GitHub (PolyML5.9.2-64bit.msi).

После установки путь к poly.exe нужно добавить в переменную PATH.
Проверка: `PolyML` (в интерактивном режиме введите `1+1;` и нажмите
Enter, для выхода - Ctrl+D).

## Запуск

Выполните запуск из PowerShell (из папки с файлом):

```powershell
PolyML --use main.sml
```

Ожидаемый вывод:
```text
original list: [1, 2, 3, 4, 5]
encoded sexp: (1 2 3 4 5)
parsed back: [1, 2, 3, 4, 5]
expected error caught: not a number: abc
```
