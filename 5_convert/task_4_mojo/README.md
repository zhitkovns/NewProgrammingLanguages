# Конвертация чисел между системами счисления

**Тема:** Конвертация данных - Mojo

## Описание задачи

Две пары прямых и обратных преобразований:

1. `Int -> String` в шестнадцатеричном виде (`int_to_hex`) и
   `String -> Int` с base 16 (`hex_to_int`). Реализовано вручную через
   деление с остатком и накопление цифр - так как не все версии Mojo
   стабильно поддерживают `String(x, format="hex")`.
2. `Float64 -> Int` через конструктор `Int(f)` (усечение вниз) и
   `Int -> Float64` через `Float64(i)`.

`int_to_hex` берет остаток от деления на 16, выбирает символ из таблицы
`0123456789abcdef`, добавляет в начало результата, делит x на 16
нацело. Цикл до нуля.

`hex_to_int` идет по символам, для каждого берет численное значение
через `hex_digit_value` и добавляет к результату как `result * 16 + d`.

`hex_digit_value` использует `ord(c)` и сравнивает коды символов, чтобы
распознать `0-9`, `a-f`, `A-F`. Невалидный символ - `raise Error(...)`.
Пустая строка - тоже ошибка.

Mojo активно развивается, API может незначительно меняться между
версиями. Код написан без специализированных библиотек, только
встроенные типы и `ord`/`String`/`Int`.

## Формат входных и выходных данных

Входных данных нет (числа заданы в main). Выходные данные: четыре
строки с результатами прямых/обратных преобразований и строка с
пойманной ошибкой.

## Установка и запуск

Mojo активно развивается, и его компилятор требует от процессора
поддержки современных инструкций (в частности, **AVX2**).

Требуется установить `uv` и создать виртуальное окружение:
```bash
uv venv
source .venv/bin/activate
uv pip install mojo --prerelease allow

mojo build main.mojo -o main
./main
```
