# Преобразование плейлиста M3U в JSON

**Тема:** Конвертация данных - Groovy

## Описание задачи

Программа парсит плейлист в расширенном формате M3U и конвертирует его
в JSON-документ. Формат M3U предполагает, что перед каждым путем к
аудиофайлу может идти строка метаданных вида:
#EXTINF:<длительность в секундах>,<Исполнитель> - <Название трека>

Программа читает текст построчно. Строки, начинающиеся с #EXTINF,
разбираются с помощью регулярного выражения. Метаданные разделяются по
разделителю " - ". Если разделителя нет, исполнитель помечается как
Unknown. Строки, не начинающиеся с #, считаются путями к файлам.

Сериализация в JSON реализована вручную (без использования
специализированных библиотек типа JsonBuilder) с корректным
экранированием кавычек и обратных слешей.

Обрабатываются ошибки: некорректный формат EXTINF, путь к файлу без
предшествующих метаданных.

## Формат входных и выходных данных

Входных данных нет, строка M3U задана в коде (переменная m3uContent).
Выходные данные - отформатированная JSON-строка в консоли.

## Установка

Требуется среда Groovy и JVM. В Windows они устанавливаются через
менеджер пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id Microsoft.OpenJDK.21 -e
winget install --id Apache.Groovy -e
```

Проверка: `groovy --version`.

## Запуск

Выполните запуск из PowerShell (из папки с файлом):

```powershell
groovy main.groovy
```

Ожидаемый вывод:
```json
[
  {
    "artist": "The Beatles",
    "title": "Come Together",
    "duration": 210,
    "path": "01 - Come Together.mp3"
  },
  {
    "artist": "The Beatles",
    "title": "Something",
    "duration": 184,
    "path": "02 - Something.mp3"
  },
  {
    "artist": "Unknown Artist",
    "title": "Mystery Track",
    "duration": -1,
    "path": "mystery.mp3"
  }
]
```
