# Двусторонняя конвертация CSV <-> JSON

**Тема:** Конвертация данных - Groovy

## Описание задачи

`csvToJson` парсит строку CSV (заголовки в первой строке, значения через
запятую) и собирает JSON вручную через `StringBuilder`. Экранирование
кавычек и обратных слэшей - в `escapeJson`. Строки с несовпадающим
числом колонок пропускаются с предупреждением в stderr.

`jsonToCsv` - обратная операция. Используется `=~` (Groovy regex find)
для поиска объектов `{...}` и пар `"key":"value"` внутри. Собирается
объединенный набор ключей (через `LinkedHashSet` для стабильного
порядка), затем печатается таблица: заголовок из ключей и строки
значений.

Round-trip: `csvToJson` -> `jsonToCsv` дает CSV с тем же набором пар
ключ-значение (порядок колонок может отличаться, если исходный CSV
не содержит всех ключей в первой строке, но в нашем случае совпадает).

Обработка ошибок: несовпадение числа колонок - предупреждение,
невалидная структура JSON (нет внешних скобок) - исключение
`IllegalArgumentException`.

## Формат входных и выходных данных

Входных данных нет - CSV-строка задана в main. Выходные данные:
исходный JSON и обратно восстановленный CSV.
