# Парсер и сериализатор INI

**Тема:** Ввод/вывод в консоль и файл - Ruby

## Описание задачи

Разбирает INI-файл в `Hash`: секция `[name]` задает текущий контекст,
пары `key=value` кладутся в хеш секции. Комментарии `;` и `#`, пустые
строки пропускаются. `split("=", 2)` режет только по первому вхождению,
поэтому значения могут содержать `=`.

Сериализация обратно: для каждой секции пишется `[section]`, затем пары
`key=value`, между секциями пустая строка. Round-trip: parse(dump(ini))
не обязан совпадать с оригиналом побайтово (порядок секций сохраняется,
внутри секций - тоже, комментарии теряются).

Обработка ошибок: строки, не подходящие под формат, пропускаются с
`warn "line N: ..."`. Отсутствие файла ловится до парсинга через
`File.exist?` и `exit 1`. `SystemCallError` в rescue - на случай ошибок
ввода-вывода при открытии (права, диск). Общий `StandardError` - на
любые другие ошибки.

## Формат входных и выходных данных

Входной файл - argv[0] или `config.ini`. Выходной файл - argv[1] или
`config_out.ini`. В консоль - сводка по секциям.

## Установка

Ruby предустановлен в большинстве дистрибутивов. Если нет:

```bash
sudo apt install ruby
```

## Запуск

```bash
ruby main.rb [config.ini] [config_out.ini]
```
