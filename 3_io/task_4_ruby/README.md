# Парсер и сериализатор INI

**Тема:** Ввод/вывод в консоль и файл - Ruby

## Описание задачи

Программа для разбора конфигурационных файлов формата INI и их обратной
сериализации.

Парсер читает файл построчно. Секции задаются в квадратных скобках
([section]). Пары ключ=значение добавляются в текущую секцию. Строки,
начинающиеся с символа ; или #, считаются комментариями и пропускаются.
Если строка не соответствует ни одному из форматов, выводится
предупреждение. Метод split("=", 2) используется, чтобы значения могли
содержать символы равенства.

После разбора данные сохраняются в хеш-таблицу (Hash) и сериализуются
обратно в текстовый файл. Исходные комментарии при этом теряются, так как
они не сохраняются в структуре данных. Обрабатываются ошибки отсутствия
файла и ошибки ввода-вывода.

## Формат входных и выходных данных

Входной файл - имя файла в argv[0] или config.ini по умолчанию.
Выходной файл - имя файла в argv[1] или output.txt по умолчанию.
Выходные данные - текстовый отчет в консоль и сериализованный INI-файл.

## Установка

Требуется интерпретатор Ruby. В Windows он устанавливается через
менеджер пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id RubyInstallerTeam.RubyWithDevKit.3.3 -e
```

Проверка: `ruby -v`.

## Подготовка тестовых данных

Создайте файл config.ini в папке с программой с таким содержимым:

```text
; global config
[database]
host=localhost
port=5432
user=admin
password=secret=with=equals

[server]
port=8080
host=0.0.0.0
timeout=30
```

## Запуск

Выполните запуск из PowerShell (из папки с файлом):

```powershell
ruby main.rb config.ini output.txt
```

Ожидаемый вывод:
```text
parsed 2 sections, 7 keys
written to output.txt
```

Файл output.txt будет содержать секции и пары ключ=значение без
комментариев, при этом значение password сохранится целиком
(secret=with=equals).
