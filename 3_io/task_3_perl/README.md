# Разбор лог-файла регулярками

**Тема:** Ввод/вывод в консоль и файл - Perl

## Описание задачи

Разбирает лог-файл в формате `IP METHOD PATH STATUS` (как access.log
без лишних полей). Регулярка `/^(\S+)\s+\S+\s+\S+\s+(\d{3})\b/`
захватывает IP и трехзначный HTTP-статус. Накопительно считает:

- общее число записей
- распределение по статусам (200/404/500/...)
- распределение по IP

Строки, не подходящие под формат, пропускаются с предупреждением в
stderr (`warn`). Выходной отчет: общее число, разбивка по статусам
(сортировка по возрастанию), топ-5 IP по частоте (сортировка по
убыванию, при равенстве - лексикографически).

Обработка ошибок через `or die "... $!"` на open/close - идиома Perl:
`$!` содержит системное сообщение. Используется `say` (Perl 5.10+),
замена `print ... \n`.

## Формат входных и выходных данных

Входной файл - argv[0] или `access.log`. Выходной файл - argv[1] или
`report.txt` (текстовый отчет).

## Установка

Perl предустановлен в большинстве дистрибутивов Linux. Если нет:

```bash
sudo apt install perl
```

## Запуск

```bash
perl main.pl [access.log] [report.txt]
```
