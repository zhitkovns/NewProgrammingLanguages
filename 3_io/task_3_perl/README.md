# Анализ структуры PNG-файла с проверкой CRC

**Тема:** Ввод/вывод в консоль и файл - Perl

## Описание задачи

Программа для разбора структуры PNG-файла на уровне байтов. PNG-файл
состоит из 8-байтовой сигнатуры и последовательности чанков (блоков).
Каждый чанк имеет структуру:
1. Длина данных (4 байта, big-endian).
2. Тип чанка (4 байта ASCII).
3. Данные (переменная длина).
4. CRC32 (4 байта, big-endian).

Программа проверяет сигнатуру, затем в цикле читает чанки, выводит их
тип и размер, а также проверяет контрольную сумму. Для строгого
соблюдения условия "без специализированных библиотек" алгоритм
вычисления CRC32 реализован вручную с использованием таблицы
полиномиальных значений.

Обрабатываются ошибки открытия файла и неверной сигнатуры.

## Формат входных и выходных данных

Входной файл - имя файла в argv[0] или test.png по умолчанию.
Выходные данные - список чанков с указанием размера и статуса CRC.

## Установка

Требуется интерпретатор Perl. В Windows он устанавливается через
менеджер пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id StrawberryPerl.StrawberryPerl -e
```

Проверка: `perl -v`.

## Подготовка тестовых данных

Создайте минимальный валидный PNG-файл (прозрачный пиксель 1x1)
с помощью PowerShell:


## Запуск

Выполните запуск из PowerShell (из папки с файлом):

```powershell
perl main.pl test.png
```

Ожидаемый вывод:
```text
PNG signature: valid
Chunks:
  IHDR: 13 bytes, CRC OK
  IDAT: 13 bytes, CRC OK
  IEND: 0 bytes, CRC OK
```
