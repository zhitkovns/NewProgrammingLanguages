# Статистика по числовой колонке CSV

**Тема:** Ввод/вывод в консоль и файл - Julia

## Описание задачи

Читает CSV-файл, парсит вторую колонку в `Float64`, собирает вектор
значений, считает count/sum/mean/min/max, пишет в файл.

Парсинг: `eachline(path)` строчно, `split(line, ',')` на колонки,
`tryparse(Float64, s)` возвращает `nothing` при ошибке парсинга. Пустые
строки пропускаются без предупреждения, строки с недостающим числом
колонок или нераспарсиваемым числом - с предупреждением `@warn`. Если
после фильтрации вектор пуст - `error(...)` (нельзя считать статистику
по пустому вектору).

Общий `try/catch` в main ловит `SystemError` от отсутствующего файла и
выводит в stderr, потом `exit(1)`.

## Формат входных и выходных данных

Входной файл - argv[1] или `data.csv`. Вторая колонка - числовая.
Выходной файл - argv[2] или `stats.txt` с полями count/sum/mean/min/max/
skipped.

## Установка

В стандартных репозиториях Ubuntu Julia либо отсутствует, либо старая.
Рекомендуется поставить через juliaup:

```bash
curl -fsSL https://install.julialang.org | sh
source ~/.bashrc
```

## Запуск

```bash
julia main.jl [data.csv] [stats.txt]
```
