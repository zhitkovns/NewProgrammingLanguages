# Слияние отсортированных бинарных записей

**Тема:** Ввод/вывод в консоль и файл - Julia

## Описание задачи

Программа демонстрирует работу с бинарными файлами и алгоритм слияния.
Запись (Record) имеет фиксированную структуру и состоит из целочисленного
ключа (Int32) и дробного значения (Float64).

Для демонстрации программа при запуске проверяет наличие двух входных
файлов (sorted_a.bin и sorted_b.bin). Если их нет, они создаются
автоматически с отсортированными ключами. Затем оба файла считываются в
память, выполняется алгоритм слияния двух отсортированных массивов
(с использованием двух указателей). Итоговый массив записывается в новый
бинарный файл merged.bin и выводится на экран.

Обрабатываются ошибки ввода-вывода с помощью блока try-catch.

## Формат входных и выходных данных

Входные данные - два бинарных файла (генерируются автоматически).
Выходные данные - бинарный файл merged.bin и текстовый вывод в консоль
с объединенными записями.

## Установка

Требуется среда выполнения Julia. В Windows она устанавливается через
менеджер пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id Julia.Julia -e
```

Проверка: `julia --version`.

## Запуск

Выполните запуск из PowerShell (из папки с файлом):

```powershell
julia main.jl
```

Ожидаемый вывод:
```text
Merged 8 records into merged.bin
Key: 1, Value: 1.5
Key: 2, Value: 3.0
Key: 3, Value: 4.5
Key: 4, Value: 6.0
Key: 5, Value: 7.5
Key: 6, Value: 9.0
Key: 7, Value: 10.5
Key: 8, Value: 12.0
```
