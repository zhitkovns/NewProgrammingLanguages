# Подсчет частот слов в файле, запись отчета

**Тема:** Ввод/вывод в консоль и файл - D

## Описание задачи

Читает текстовый файл, приводит к нижнему регистру, чистит слова от
пунктуации (оставляя только a-z0-9), считает частоты в ассоциативном
массиве `int[string]` (это встроенная хеш-таблица D). Затем сортирует
по убыванию частоты, при равенстве - по алфавиту, пишет в выходной
файл в два столбца с выравниванием.

Разбор словаря: `content.split` режет по пробельным символам, `filter`
по предикату `c >= 'a' && c <= 'z' || c >= '0' && c <= '9'` выкидывает
пунктуацию, конкатенация собирает обратно в строку. Результат -
`byKeyValue.array` + `sort!` с компаратором.

Обработка ошибок: обертка `try/catch (Exception e)` вокруг чтения и
записи. Если файла нет - `FileException` с сообщением.

## Формат входных и выходных данных

Входной файл - имя в argv[1] или `input.txt` по умолчанию. Выходной
файл - `output.txt`. В консоль - сводка (сколько уникальных слов и
куда записано). В выходной файл - пары `слово  частота`.

## Запуск

```bash
dmd main.d
./main [input.txt]
