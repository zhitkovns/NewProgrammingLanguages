# Анализ WAV-файла

**Тема:** Ввод/вывод в консоль и файл - D

## Описание задачи

Программа для чтения и анализа заголовка WAV-файла. Она открывает файл
в бинарном режиме, проверяет сигнатуры RIFF и WAVE, а затем извлекает
метаданные из чанка fmt (формат аудио, количество каналов, частота
дискретизации, разрядность).

Затем программа ищет чанк data, чтобы определить размер аудиоданных, и
вычисляет длительность звучания в секундах. Обрабатываются ошибки
отсутствия файла, слишком маленького размера файла и некорректного
заголовка.

## Формат входных и выходных данных

Входной файл - имя файла в argv[1] или test.wav по умолчанию.
Выходные данные - текстовый отчет с параметрами аудиофайла.

## Установка

Требуется компилятор DMD. В Windows он устанавливается через менеджер
пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id Dlang.DMD -e
```

Проверка: `dmd --version`.

## Подготовка тестовых данных

Создайте тестовый WAV-файл (1 секунда тишины, 8000 Гц, 8 бит, моно).
Это удобнее сделать в терминале MSYS2 UCRT64, так как используются
стандартные бинарные утилиты:

```bash
printf "RIFF\x64\x1f\x00\x00WAVEfmt \x10\x00\x00\x00\x01\x00\x01\x00\x40\x1f\x00\x00\x40\x1f\x00\x00\x01\x00\x08\x00data\x40\x1f\x00\x00" > test.wav
head -c 8000 /dev/zero | tr '\0' '\200' >> test.wav
```

Проверка размера файла (должно быть 8044 байта):
```bash
ls -l test.wav
```

## Запуск

Выполните компиляцию и запуск из PowerShell (из папки с файлом):

```powershell
dmd main.d
.\main.exe test.wav
```

Ожидаемый вывод:
```text
WAV file: test.wav
Audio format: PCM
Channels: 1
Sample rate: 8000 Hz
Bits per sample: 8
Duration: 1 seconds
```
