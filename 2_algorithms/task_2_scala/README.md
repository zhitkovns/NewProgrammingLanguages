# Бинарное дерево поиска: вставка, обход, высота

**Тема:** Алгоритмические задачи - Scala

## Описание задачи

Реализация бинарного дерева поиска (BST) с использованием алгебраического
типа данных (ADT). Дерево описывается через `sealed trait Tree`, который
имеет два наследника: `Empty` (пустое дерево) и `Node(value, left, right)`
(узел со значением и двумя поддеревьями).

Все операции реализованы рекурсивно с использованием сопоставления с
образцом (pattern matching):
- `insert` - вставляет значение, спускаясь по дереву. Дубликаты игнорируются.
- `contains` - проверяет наличие значения в дереве.
- `inOrder` - выполняет симметричный обход (возвращает отсортированный список).
- `height` - вычисляет высоту дерева (максимальную глубину).

## Формат входных и выходных данных

Входных данных нет, список значений для построения дерева задан в `main`.
Выходные данные: отсортированный обход дерева, высота, результаты поиска
двух элементов.

## Установка

Требуется Scala CLI и JVM. В Windows они устанавливаются через менеджер
пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id Microsoft.OpenJDK.21 -e
winget install --id VirtusLab.ScalaCLI -e
```

Проверка: `scala-cli version`.

## Запуск

Выполните запуск из PowerShell (из папки с файлом). Scala CLI
автоматически скачает нужные зависимости и скомпилирует программу:

```powershell
scala-cli main.scala
```

Ожидаемый вывод:
```text
in-order: 20, 30, 35, 40, 50, 60, 70, 80
height: 4
contains 40: true
contains 45: false
```
