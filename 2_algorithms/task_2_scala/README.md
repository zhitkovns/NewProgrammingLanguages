# Бинарное дерево поиска: вставка, обход, высота

**Тема:** Алгоритмические задачи - Scala

## Описание задачи

Алгебраический тип дерева: `sealed trait Tree` с двумя случаями `Empty`
и `Node(value, left, right)`. Такой sealed trait в Scala дает
исчерпывающий pattern matching - компилятор предупредит, если в match
забыт случай.

Операции рекурсивные:
- `insert` спускается по дереву сравнением, пересобирает ветви
- `contains` - булев поиск
- `inOrder` - симметричный обход (возвращает отсортированный список)
- `height` - высота через `1 + max(...)`

Дерево строится из списка через `foldLeft` начиная с `Empty`. Дубликаты
не вставляются - второй `insert` с тем же значением возвращает дерево
без изменений.

## Формат входных и выходных данных

Входных данных нет - список значений задан в main. Выходные данные:
отсортированный обход, высота, два ответа на вопрос `contains`.
