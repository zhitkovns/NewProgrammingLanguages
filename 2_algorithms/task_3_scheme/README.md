# Рекурсивное решение задачи о Ханойских башнях

**Тема:** Алгоритмические задачи - Scheme

## Описание задачи

Классическая рекуррентная формула: чтобы переложить n дисков со
стержня `from` на `to` через промежуточный `via`, нужно

1. переложить n-1 дисков с `from` на `via` через `to`
2. переложить самый большой диск с `from` на `to`
3. переложить n-1 дисков с `via` на `to` через `from`

В Scheme это буквально переписывается на `append` трех списков: два
рекурсивных вызова плюс один ход. Базовый случай - n=0, пустой список.

`print-moves` проходит по списку пар через `for-each`. `let*` нужен,
чтобы `count` зависел от уже вычисленного `moves` (в обычном `let`
параметры вычисляются параллельно).

## Формат входных и выходных данных

Входных данных нет (число дисков = 3 задано в main). Выходные данные:
список ходов `A -> C` построчно и общее число ходов.

## Запуск

```bash
guile main.scm
```
Подойдет любой интерпретатор Scheme - также запустится в Racket,
Chibi, Chez.
