# Поиск минимального вершинного покрытия дерева

**Тема:** Алгоритмические задачи - Scheme

## Описание задачи

Вершинное покрытие графа - это набор вершин, такой что каждое ребро
графа имеет хотя бы одну вершину из этого набора. Задача состоит в
нахождении покрытия минимального размера для заданного дерева.

Алгоритм использует динамическое программирование на деревьях и рекурсию.
Для каждого узла вычисляются два значения:
1. Размер покрытия, если этот узел включен (тогда его дети могут быть
   как включены, так и нет, мы выбираем минимум).
2. Размер покрытия, если этот узел не включен (тогда все его дети
   обязательно должны быть включены).

Функция `solve` рекурсивно обходит дерево и возвращает пару `(include . exclude)`.
Итоговый ответ - минимум из этих двух значений для корня дерева.

## Формат входных и выходных данных

Входных данных нет, дерево задано в виде вложенного списка в коде.
Выходные данные - одно число: минимальный размер вершинного покрытия.

## Установка

Требуется интерпретатор Scheme. В Windows он устанавливается через среду MSYS2.

1. Откройте терминал MSYS2 UCRT64.
2. Выполните установку пакета:

```bash
pacman -S guile
```

Проверка: `guile --version`.

## Запуск

Выполните запуск из терминала MSYS2 UCRT64:

```bash
guile main.scm
```

Ожидаемый вывод:
```text
Min vertex cover size: 2
```
