# Рекурсивное сопоставление строк с шаблоном

**Тема:** Алгоритмические задачи - Haskell

## Описание задачи

Реализация алгоритма проверки, соответствует ли строка заданному шаблону.
Шаблон может содержать обычные символы, а также спецсимволы:
- `?` соответствует ровно одному любому символу
- `*` соответствует любой последовательности символов (включая пустую)

Алгоритм реализован рекурсивно с использованием сопоставления с образцом
(pattern matching) по спискам символов. В случае встречи с символом `*`
применяется рекурсивный перебор с возвратом (backtracking): мы пробуем
сопоставить оставшуюся часть шаблона с текущей позицией строки (если `*`
соответствует пустой строке), либо пропускаем один символ в строке и
пробуем снова.

## Формат входных и выходных данных

Входных данных нет, тестовые пары (шаблон, строка) заданы в функции `main`.
Выходные данные - построчный вывод результата сопоставления для каждой пары.

## Установка

Требуется компилятор GHC (Glasgow Haskell Compiler). В Windows он
устанавливается через менеджер пакетов winget.

Выполните в PowerShell:
```powershell
winget install --id commercialhaskell.stack -e
```

При первом запуске `stack` автоматически скачает компилятор GHC.
Проверка: `stack ghc -- --version`.

## Запуск

Выполните компиляцию и запуск из PowerShell (из папки с файлом):

```powershell
stack ghc main.hs
./main.exe
```

Ожидаемый вывод:
```text
"a*b?c" matches "a123bXc": True
"a*b?c" matches "a123bc": False
"hello*" matches "hello world": True
"*world" matches "hello world": True
"*" matches "anything": True
"h?llo" matches "hello": True
"h?llo" matches "hllo": False
```
