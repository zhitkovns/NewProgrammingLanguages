# Рекурсивный разбор и вычисление арифметических выражений

**Тема:** Алгоритмические задачи - Haskell

## Описание задачи

Рекурсивный спуск для арифметики с приоритетами: + и - ниже, чем * и /,
скобки меняют порядок. Каждый уровень грамматики - отдельная функция,
которая возвращает `(значение, остаток-токенов)`:

- `parseExpr = parseAdd`
- `parseAdd` чередует `parseMul` и разбор +/-
- `parseMul` чередует `parseAtom` и разбор */÷
- `parseAtom` - число или выражение в скобках

Токенизация отделена от разбора. Для разбора токенов используется
pattern matching по списку: `(TPlus:ts)` отделяет первый токен от
остальных. Это идиоматический для Haskell способ разбора без
сторонних библиотек.

Ошибки: неожиданный символ при токенизации, деление на ноль, отсутствие
закрывающей скобки, лишние токены после выражения - все через `error`.
Это не самый аккуратный способ обработки ошибок в Haskell (лучше
`Either String Int`), но для демонстрации подходит.

## Формат входных и выходных данных

Входных данных нет - список выражений задан в main. Выходные данные:
построчно `выражение = значение`.
