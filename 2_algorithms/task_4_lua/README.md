# Построение суффиксного массива

**Тема:** Алгоритмические задачи - Lua

## Описание задачи

Суффиксный массив - это массив, содержащий начальные позиции всех
суффиксов строки, отсортированных в лексикографическом порядке.

Алгоритм реализован с использованием метода префиксного удвоения
(prefix doubling). Изначально суффиксы сортируются по первому символу.
Затем, на каждом шаге, длина сравниваемого префикса удваивается, и
суффиксы сортируются по парам (текущий ранг, ранг соседа на расстоянии k).

Процесс удвоения реализован рекурсивно в функции `sort_step`: на каждом
уровне рекурсии шаг `k` умножается на 2. Базовый случай рекурсии - когда
длина шага `k` достигает длины строки, сортировка завершена.

## Формат входных и выходных данных

Входных данных нет, строка задана константой в коде.
Выходные данные - индексы начала суффиксов в отсортированном порядке.

## Установка

Требуется интерпретатор Lua. В Windows он устанавливается через среду MSYS2.

1. Откройте терминал MSYS2 UCRT64.
2. Выполните установку пакета:

```bash
pacman -S mingw-w64-ucrt-x86_64-lua
```

Проверка: `lua -v`.

## Запуск

Выполните запуск из терминала MSYS2 UCRT64:

```bash
lua main.lua
```

Ожидаемый вывод:
```text
Suffix array for 'banana': 6 4 2 1 5 3
```
