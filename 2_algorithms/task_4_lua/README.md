# Рекурсивный перебор задачи о N ферзях

**Тема:** Алгоритмические задачи - Lua

## Описание задачи

Расставить N ферзей на доске N x N так, чтобы они не били друг друга.
Рекурсивный бэктрекинг: ставим ферзя в текущую строку, перебирая
столбцы; после каждой постановки рекурсивно переходим к следующей
строке; при неудаче откатываем.

Проверка конфликтов за O(1): три хеш-таблицы:
- `cols[col]` - занятый столбец
- `d1[row+col]` - главная диагональ (индекс одинаков вдоль нее)
- `d2[row-col+n]` - побочная диагональ (сдвиг на n, чтобы индекс был
  положительным)

Флаг ставится перед рекурсией и снимается после - классический
backtracking. `first_solution` сохраняет первое найденное решение в
отдельный массив (иначе на выходе из рекурсии `current` был бы уже
перезаписан).

`n=8` - классические 8 ферзей, 92 решения.

## Формат входных и выходных данных

Входных данных нет (n = 8 в main). Выходные данные: число решений и
первое найденное в виде "столбец по строке 1..n".


## Запуск
